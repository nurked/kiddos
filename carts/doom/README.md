# Doom

Doom, from 1993, is where first-person 3D games began. The program here is
the real Doom engine (id Software published its source in 1997; this is
the `doomgeneric` version, made to run anywhere), compiled with `cc` into a
KidDOS program. The levels, monsters and pictures are Freedoom's, made by
volunteers so that the game can be given away.

Arrows turn and walk, A and D step sideways, X shoots, SPACE opens doors,
Esc opens the menu, Enter chooses, Tab shows the map. You always run.

It is a program like any other on this machine: it can only draw on the
screen and read its own files. Saved games go to `~/.doom`.
