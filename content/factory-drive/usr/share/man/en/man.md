# man
> read the manual for a command

## WHAT IT DOES
Every command has a page in the manual. `man` shows it. You are reading
one now. Long pages stop at the bottom of the screen: press Space for
more, q to quit.

## TRY THIS
```
man ls
man -k folder
man pipes
```

## OPTIONS
- `-k word` search all pages for a word (same as `apropos`)

## SEE ALSO
help, apropos

## GROWN-UP NOTE
Real man pages are terser and use the same section names. The habit of
typing `man x` transfers directly.
