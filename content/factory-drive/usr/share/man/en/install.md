# install
> install a .kdc cartridge: install rocket

## WHAT IT DOES
Parent mode only. Reads a `.kdc` file from the cartridge folder on the
real computer and puts the game into /games. `carts` shows what is in the
folder and where the folder is. An existing game with the same name is
replaced.

## TRY THIS
```
parent
carts
install rocket
exit
play rocket
```
