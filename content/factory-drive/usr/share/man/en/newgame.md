# newgame
> start your own game: newgame rocket

## WHAT IT DOES
Makes a folder in your home with everything a game needs: a BASIC
program that already runs, a cart.toml that names it, a README and a
manual page. Change the program; it is yours.

## TRY THIS
```
newgame rocket
run ~/rocket/rocket.bas
edit ~/rocket/rocket.bas
cat ~/rocket/cart.toml
```

## SHARING
When it is good, a parent can turn the folder into one file to give to a
friend: in parent mode, `share /home/kid/rocket`. On the friend's
machine, a parent runs `install rocket`, and `play rocket` works there.
