# edit
> write or change a file (a text editor)

## WHAT IT DOES
Opens a file so you can type into it. The top line shows the file name,
the bottom line shows the keys. When you are done, Ctrl-S saves and
Ctrl-Q quits. If you forget to save, it asks.

## TRY THIS
```
edit story.txt
cat story.txt
edit ~/bin/hello
```

## KEYS
- `Ctrl-S` save
- `Ctrl-Q` quit
- `Ctrl-K` cut the whole line (press again to cut more lines)
- `Ctrl-U` paste the cut lines back
- Arrows, Home, End, PageUp, PageDown move around

## GROWN-UP NOTE
The keys are nano's. A kid who knows edit can sit down at nano on any
Linux box. vi comes later, as a game.
