# ls
> list what is in a folder

## WHAT IT DOES
Shows the names of the files and folders in a folder. With no folder
name, it shows the one you are in right now.

## TRY THIS
```
ls
ls -l
ls /games
ls -a ~
```

## OPTIONS
- `-l` long form: shows who owns each file, how big it is, and when it changed
- `-a` all: also shows hidden files (names that start with a dot)
- `-h` human sizes: 2.3K instead of 2400
- `-1` one name per line

## SEE ALSO
cd, pwd, tree, find

## GROWN-UP NOTE
Works the same on Linux and macOS. Folders are blue, programs are green,
links are cyan — real terminals color them the same way.
