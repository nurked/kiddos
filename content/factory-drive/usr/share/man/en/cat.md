# cat
> show what is inside a file

## WHAT IT DOES
Prints a file on the screen. Give it two files and it prints both, one
after the other (that is where the name comes from: con-cat-enate).

## TRY THIS
```
cat welcome.txt
cat -n welcome.txt
cat /etc/motd /etc/hostname
```

## OPTIONS
- `-n` number every line

## SEE ALSO
less, head, tail, echo

## GROWN-UP NOTE
`cat` with no file reads from the keyboard until Ctrl-D. Try it.
