# cd
> go into a folder

## WHAT IT DOES
Changes the folder you are in. `cd` alone takes you home. `cd ..` goes up
one level. `cd -` goes back where you just were.

## TRY THIS
```
cd /games
cd ..
cd ~
cd -
```

## SEE ALSO
pwd, ls, mkdir

## GROWN-UP NOTE
`cd` is built into the shell, not a separate program, because a program
cannot change the folder of the shell that started it. Same on Linux.
