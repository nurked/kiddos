# wasm
> run a compiled program (.wasm)

## WHAT IT DOES
Runs a WebAssembly program. You rarely type it: `./hello.wasm` does the
same, because the machine sees what kind of file it is. Programs come
from `cc` (C), or from a cartridge that ships a `.wasm`.

## TRY THIS
```
cc hello.c
wasm hello.wasm
./hello.wasm
```
