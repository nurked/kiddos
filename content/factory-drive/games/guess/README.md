# Guess the Number

The machine picks a number from 1 to 100. You guess. It says higher or
lower. That's the whole game, and it is 25 lines of BASIC.

Read it: `cat /games/guess/guess.bas`. Copy it and make it yours:

```
cp /games/guess/guess.bas ~/mygame.bas
edit ~/mygame.bas
run ~/mygame.bas
```
