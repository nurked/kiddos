# rogue
> a dungeon crawler written in C, compiled to wasm

## TRY THIS
```
play rogue
cat /games/rogue/rogue.c | less
```
Arrows move. Walk into monsters. `p` drinks a potion, `>` on the stairs
goes deeper, `?` shows help, ESC quits. The whole game is one C file that
uses nothing but kiddos.h.
