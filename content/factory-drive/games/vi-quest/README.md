# vi-quest

vi is the editor grown-ups use on every server in the world. It has no
menus. Instead it has *spells*: h j k l to move, w to jump a word, x to
delete, dd to cut a line, / to find. This quest teaches them one land at
a time. The cursor is you. Stone `#` blocks you. `X` is the way out.

Finish the last land and a new word appears in /bin: `vi`.

The lands are text files: `ls /games/vi-quest/levels`. You can read
them, and you can draw your own.
